# Changelog

## [0.2.8] - Alpha

### Added

- Expose typed Bedrock diagnostic reads for Cryptarchia headers, network
  information, and Mantle metrics through LogosCore.

## [0.2.7] - Alpha

### Fixed

- Recover a Basecamp Bedrock lifecycle context from its existing configuration after host recreation.

### Added

- Versioned managed-node lifecycle status, actions, and change events for Bedrock hosts.

### Fixed

- Preserve a running Bedrock node when its stop operation fails.
- Clean up a started node when block-event subscription setup fails.

## [0.2.5] - Alpha

### Added

- Source-owned prerelease workflow for merged portable Linux AMD64 and macOS ARM64 LGX packages.
